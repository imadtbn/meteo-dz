# المرحلة الرابعة — مطابقة صفحات الولايات المستقلة

المعاينة معزولة تحت `/vanilla-preview/` ولا تستبدل مسارات الإنتاج.

## ما تتضمنه
- صفحة رئيسية HTML مولّدة وقت البناء و69 صفحة ولاية مستقلة.
- المرصد المناخي: سجل يومي من NASA POWER مع ملخص الحرارة والأمطار والرسوم البيانية.
- الطقس الزراعي: مؤشرات GDD والأمطار وأيام الصقيع والحرارة والأيام الممطرة حسب الولاية، مع فترات 30/90 يوماً ودرجة أساس قابلة للتعديل.
- بحث عربي وفرنسي ولاتيني، والمنطقة ورمز الولاية ورمز الهاتف.
- القراءة الحالية: الحرارة والمحسوس والرطوبة والرياح واتجاهها والهطول والغيوم.
- توقعات ساعية للـ12 ساعة القادمة وتوقعات يومية لسبعة أيام.
- بيانات بحرية اختيارية للولايات الساحلية، دون تعطيل النشرة البرية عند فشل مصدر البحر.
- مصدر احتياطي GFS عند تعذر خدمة التوقعات الأساسية.
- مهلة اتصال محددة، ورسالة انقطاع واضحة، وذاكرة مؤقتة 15 دقيقة مع إظهار آخر قراءة محفوظة حتى 6 ساعات عند تعذر المصدر.
- المفضلة تستخدم المفتاح الحالي `atlas-favorite-cities-v1`، والثيم يستخدم `theme`.
- CSS وJavaScript مستقلان عن React وWouter، مع تصميم متجاوب.

## ما لم يكتمل بعد
لا تزال الخرائط التفاعلية، والتنبيهات الرسمية الحية، والخرائط الجوية، وصفحات المرصد المناخي والزراعة، وبقية وظائف التطبيق قيد المطابقة. لا تُعلن هذه النسخة بديلًا عن React قبل اختبار التكافؤ الوظيفي الشامل.

## ضمانات السلامة
- لا تُعدّل هذه المرحلة أي صفحة أو مكوّن أو مسار إنتاج تابع لنسخة React.
- جميع صفحات المعاينة تحمل `noindex,nofollow` حتى اعتماد النقل النهائي.
- لا يجري تغيير المسارات المنشورة أو خريطة الموقع أو إعدادات PWA الحالية.
- يتم توليد الصفحات من `client/src/data/cities.json` مباشرة، مع فحص وجود 69 ولاية فريدة وغياب رموز القوالب غير المستبدلة.

## البناء والتحقق
يُشغّل `scripts/generate-vanilla-pages.mjs` بعد بناء الموقع، ثم يتحقق `scripts/verify-vanilla-pages.mjs` من البيانات والقوالب والميزات والملفات المطلوبة. البناء الأساسي واختبارات React الحالية يظلان جزءًا من CI دون تغيير.
